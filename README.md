# Student Performance Prediction

## Project Description

This is a Data Science project that predicts students' final scores
using study hours, attendance, and previous scores.

## Objective

The objective of this project is to predict the final performance
of a student using machine learning.

## Features

- Study Hours
- Attendance
- Previous Score

## Target Variable

- Final Score

## Machine Learning Algorithm

Linear Regression

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Git
- GitHub

## Steps Performed

1. Created the student performance dataset.
2. Loaded the data using Pandas.
3. Separated features and target variable.
4. Split the data into training and testing sets.
5. Trained a Linear Regression model.
6. Predicted student final scores.
7. Evaluated the model using Mean Squared Error and R2 Score.
8. Visualized actual and predicted scores.

## Conclusion

The Linear Regression model is used to predict student final scores
based on study hours, attendance, and previous academic performance.
